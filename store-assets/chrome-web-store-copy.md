# Chrome Web Store Copy

## Short Description

Download course materials from SUT e-Learning into organized folders.

## Detailed Description

SUT e-Learning Scraper helps students download course materials from SUT e-Learning and save them into neatly organized folders on their computer.

Features:

- Scans the current SUT e-Learning course page for downloadable materials
- Groups files by course and section
- Downloads selected materials into a structured folder layout
- Can package selected materials into a ZIP file
- Saves local preferences such as folder name and ZIP option

This extension works only on:

- https://elearning5.sut.ac.th/*

The extension is designed for user-initiated downloads only. It does not sell user data, does not run remote code, and stores settings locally in the browser.

## Single Purpose

This extension helps SUT students download course materials from SUT e-Learning into organized folders on their computer.

## Privacy Practices Copy

### Downloads Permission

Required to save the course files selected by the user to the user's Downloads folder in organized course and section subfolders.

### Storage Permission

Required to save the user's local extension settings, including the destination subfolder name, ZIP preference, progress state, and detected downloads path.

### Host Permission Justification

Required to access https://elearning5.sut.ac.th/* so the extension can read course pages, identify downloadable materials, and resolve file links for the signed-in user.

### Remote Code Use Justification

This extension does not use remote code. All executable logic is packaged within the extension. Network requests are used only to read course pages and download user-selected files from the authorized SUT e-Learning site.

### Data Usage Statement

The extension processes course page content on https://elearning5.sut.ac.th only to identify and download materials selected by the user. Settings are stored locally in the browser. The extension does not sell data, use data for advertising, or transfer data to third parties except as required to retrieve files from the SUT e-Learning site at the user's request.
