Privacy Policy for SUT e-Learning Scraper

Effective date: May 6, 2026

SUT e-Learning Scraper is a browser extension that helps users download course materials from SUT e-Learning into organized folders on their own computer.

Information We Process

  • Course page content from https://elearning5.sut.ac.th/*
  • Links to downloadable course materials
  • User-selected extension settings such as folder name and ZIP preference

How Information Is Used

  • Detect downloadable materials on SUT e-Learning course pages
  • Resolve file links for user-requested downloads
  • Save files selected by the user
  • Store local extension settings in the browser

Data Storage

The extension stores settings locally in the user's browser using Chrome extension storage.

The extension does not maintain a remote database and does not transmit stored settings to the developer.

Data Sharing

The extension does not sell, rent, or share personal information with third parties.

Network requests are made only as needed to access SUT e-Learning pages and files requested by the user.

Remote Code

The extension does not execute remote code. All executable code is packaged with the extension.

User Control

Users control when the extension runs by opening the extension on a supported SUT e-Learning course page and starting a scan or download.

Users can remove the extension at any time and clear extension data through their browser settings.
