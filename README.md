# SUT e-Learning Scraper

SUT e-Learning Scraper is a Chrome extension that helps students download course materials from SUT e-Learning into organized folders on their computer.

## Features

- Scans supported SUT e-Learning course pages for downloadable materials
- Groups files by course and section
- Downloads files into a structured folder layout
- Supports optional ZIP export
- Stores preferences locally in the browser

## Supported Site

- `https://elearning.sut.ac.th/*`
- `https://elearning5.sut.ac.th/*` (legacy domain)

## Privacy

The extension stores settings locally and only accesses SUT e-Learning pages needed to identify and download materials selected by the user.
